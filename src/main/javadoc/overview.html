Welcome to the Java documentation of the Keypop Crypto Asymmetric Java API, part of the Keypop open-source project hosted by the Eclipse Foundation.

Aligned with version 0.2 of the Terminal Calypso Crypto Asymmetric API specification issued by the Calypso Networks Association (available here), which carries the normative contract of each type and operation documented below, it defines the generic interfaces required to implement a card transaction secured by an asymmetrical key cryptography module (e.g. PKI).
